# Посмотри в окно

Учебный проект Яндекс Практикума — одностраничный сайт для поиска и просмотра коротких видео с видами из окон разных городов.

Проект выполнен по макету Figma с использованием HTML и CSS. Основная задача — оформить готовую разметку, передать композицию макета и сохранить функциональность предоставленного JavaScript.

## О проекте

Страница включает:

- основной видеоплеер с элементами управления;
- форму поиска по названию города;
- фильтры по времени суток: утро, день и ночь;
- заголовок проекта;
- прокручиваемый список карточек с названиями городов, описаниями и превью;
- кнопку «Показать ещё» для загрузки следующих результатов;
- прелоадеры и сообщения об ошибках.

Минимальная ширина страницы — 1200 px. Ширина основного контента — 1140 px. Проект ориентирован на экраны ноутбуков и настольных компьютеров.

## Исходные материалы

- [Макет проекта в Figma](https://www.figma.com/design/UaTcfbXdgWIbT0x7OoGHOS/?node-id=1-214).
- [Мой репозиторий на GitHub](https://github.com/Katrinn24/posmotri-v-okno-ad).

Для работы использованы предоставленные HTML-разметка, JavaScript, стили прелоадера и сообщений об ошибках, а также локальные шрифты Fira Sans Condensed и Oswald. Данные карточек, изображения и видео загружаются с сервера проекта.

## Что выполнено

1. Настроены базовые стили страницы и сброс стандартных отступов.
2. Создана раскладка двух колонок с помощью Flexbox.
3. Оформлены видеоплеер, форма поиска и список результатов.
4. Использованы локальные шрифты Fira Sans Condensed Regular, Fira Sans Condensed Bold и Oswald Bold.
5. Добавлены пользовательские чекбоксы; выбранное состояние оформлено псевдоэлементом.
6. Реализованы состояния наведения, нажатия и клавиатурного фокуса интерактивных элементов.
7. Настроены размеры и обрезка видео и изображений с помощью object-fit.
8. Оформлена прокрутка списка карточек.
9. Сохранена работа исходного JavaScript: поиск, переключение видео, загрузка следующих результатов, прелоадеры и сообщения об ошибках.

В основном файле style.css абсолютное позиционирование используется только для класса visually-hidden.

## Технологии

| Технология | Применение |
| --- | --- |
| HTML5 | Разметка страницы, форма, видеоплеер и шаблоны карточек |
| CSS3 | Оформление страницы и состояния элементов |
| Flexbox | Раскладка основных блоков |
| Псевдоклассы и псевдоэлементы | Состояния элементов и оформление чекбоксов |
| JavaScript | Предоставленная логика поиска и загрузки видео |
| Fetch API | Запросы к серверу проекта |
| Локальные шрифты WOFF2 и WOFF | Типографика |
| Git и GitHub | Контроль версий и хранение проекта |

## Структура и организация файлов

| Файл или папка | Назначение |
| --- | --- |
| index.html | Разметка страницы и шаблоны динамических элементов |
| styles/style.css | Основные стили, раскладка и состояния элементов |
| styles/preloader.css | Оформление и анимация прелоадера |

| fonts/fonts.css | Подключение локальных шрифтов |

| .github/workflows/tests.yml | Конфигурация проверок GitHub Actions |
| README.md | Описание проекта |

## Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Запустите index.html через расширение Live Server.

Установка зависимостей и сборка не требуются.

Для загрузки карточек и воспроизведения видео необходим доступ к серверу https://v-content.practicum-team.ru. При недоступности сервера поиск и загрузка видео не смогут завершиться успешно.
